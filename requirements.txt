# --- File intake parsers (Phase 2) ---
# Licensing: BSD-3 / MIT, compatible with this repository's MIT licence. PyMuPDF extracts PDF
# text better than pypdf but is AGPL-3.0, so it is deliberately not used - a dependency that
# changes the terms for anyone embedding this harness outweighs extraction quality.
#
# Installation: this project requires no separate system binary. On the environments it targets
# these install from pip wheels in the normal way. Note that the transitive tree is not
# dependency-free: python-docx pulls in lxml, and python-pptx pulls in lxml, Pillow and
# XlsxWriter, some of which ship compiled extensions. Wheels are published for the common
# platforms, but this is not a guarantee that nothing is ever built from source.
#
# No OCR: Tesseract or any other external system binary is out of scope for Phase 2.
#
# Each parser imports its library lazily, so a deployment that only ingests CSV and TXT can
# leave these uninstalled and gets a PARSER_UNAVAILABLE code instead of a startup failure.
pypdf>=5.0            # BSD-3  PDF text layer (no OCR). No required runtime deps on Python 3.11+
python-docx>=1.1      # MIT    DOCX. Requires lxml
python-pptx>=1.0      # MIT    PPTX. Requires lxml, Pillow, XlsxWriter
openpyxl>=3.1         # MIT    XLSX. Requires et-xmlfile

# --- LLM adapters (Phase 8) ---
# Nothing here. adapters/llm/anthropic.py speaks to the Messages API with the standard
# library: it is one POST with a JSON body, and it takes its transport as a constructor
# argument, so an organisation that prefers the official SDK installs and injects it without
# this file changing. The SDK was measured rather than guessed at - it resolves to 13
# packages including two compiled extensions - and its default retry behaviour is not zero,
# which this harness needs it to be: a retry re-sends the client's evidence. See
# adapters/README.md.
#
# jsonschema above is what validates structured output against the requested schema. Without
# it the adapter stops with LLM_SCHEMA_VALIDATOR_UNAVAILABLE rather than returning a value it
# has not checked.

# --- Search adapters (Phase 8) ---
# Nothing here either. adapters/search/brave.py speaks to the Web Search API with the standard
# library: it is one GET with seven query parameters, and it takes its transport as a
# constructor argument, so an organisation that prefers requests/httpx installs and injects it
# without this file changing.
#
# This was re-derived rather than copied from the LLM adapter's conclusion: the provider
# publishes no official Python SDK worth adopting, and a general-purpose HTTP client would
# bring a retry policy this harness needs to own itself (a retry re-sends the query). See
# adapters/README.md.
